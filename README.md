# Hustle Engine

Strategic project manager for founders at the zero-to-one phase.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- [Tailwind CSS](https://tailwindcss.com) v4

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
